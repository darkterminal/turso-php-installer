---
title: Update
description: Update the LibSQL PHP extension installed by the Turso PHP Installer to the latest release.
section: Guide
eyebrow: Lifecycle
---

```bash
turso-php-installer update
```

The update command refreshes the installed extension from the latest release of the configured source.

---
title: Uninstall
description: Remove the LibSQL PHP extension installed by the Turso PHP Installer.
section: Guide
eyebrow: Lifecycle
---

```bash
turso-php-installer uninstall
```

The uninstall command removes the installed extension binary and cleans the installer state.
